# Forest (`ForestRun`, `ForestShop`)

`src/scenes/minigames/forest/`: endless first-person shooter on a forest path. It is pseudo-3D done by hand: entities have world `x`/`z`, `proj()` (`projection.ts`) maps them to the screen (`s = FOCAL/(FOCAL+z)`, depth = `-z`), and the path is redrawn each frame into a Graphics. `ForestRun.ts` is the scene (input, shooting, update loop, entities, end of run) and delegates to: `state.ts` (`RunState`/`Ent`: everything that changes in a run, created fresh by `newRun()` in `create()`, so "Play again" needs no manual reset: put new per-run numbers there, not on the scene), `quests.ts` (`QuestLog`, no Phaser), `director.ts` (`chooseSpawn`/`spawnInterval`, no Phaser), `motion.ts` (`stepMotion`, no Phaser), `boss.ts` (the demon), `backdrop.ts` (sky, ground, worlds, weather), `hud.ts` and `endScreen.ts`. Enemy/item stats, quest templates and how things move live in `forestData.ts`: `Def.move` (`homing`, `sway`, `bob`, `hop`, `drift`, `drop`) describes a monster's movement as data, so a new ordinary monster is one `DEFS` row plus art, a bag entry in `biomes.ts` and a quest key; only the troll's throws and the demon have code (`Def.boss`/`Def.solid`/`Def.tint` flag bosses, un-shootable fireballs and re-tinted art); art is `src/art/{forest,cave,arctic,hell}-*.svg` and `fireball.svg`. Left-bottom joystick strafes, any other tap shoots at that point (hold to keep firing with auto weapons).

The run passes through four **worlds** by distance (`biomes.ts`: forest 0 m, cave 250, arctic 600, hell 1000). A `Biome` holds the sky/ground gradients, path colours, decor, spawn `bag`, quest pool and weather; `ForestBackdrop.setBiome()` crossfades to the next one (`ForestRun.enterBiome()` then drops quests that can't be done there via `QuestLog.adaptTo()`). In hell the demon (`BOSS_AT_M`) hovers at `BOSS_Z` (`boss.ts`), swings left and right and throws fireballs along three lanes that can only be dodged (it turns red just before a volley); killing it calls `victory()`. Dev only: `?m=1150` starts the run that many metres in.

## Weapons and coins

`forest/weapons.ts`, `forest/ForestShop.ts`, `src/core/forestSave.ts`: `WEAPONS` defines pistol/shotgun/smg/laser/rocket (damage, magazine, reload, cooldown, `mode` nearest|splash|pierce, `auto`). The forest earns coins per action into the shared wallet (see **Wallet** in `CLAUDE.md`). `forestSave` (`forest-save`) keeps only the owned weapons, the equipped one, the best distance and a run counter (the first 3 runs show longer hints); `profile` takes over the coins an old `forest-save` held. The forest's stars are `forestStars()` (`stars.ts`), banked the moment a run ends. `ForestShop` always goes on to `ForestRun`; it is opened by the gate's first visit (`enterStage()` in `stages.ts`) and from the end-of-run screen.

The town side of the forest (the gate at the end of the north path, `northZones`) is described under **City journey** in `CLAUDE.md`.
